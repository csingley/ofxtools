# Contributing to ofxtools

See the [contributor documentation](https://ofxtools.readthedocs.io/en/latest/contributing.html)
for setup instructions, how to run the tests and linter, and a full worked
example of adding new OFX message types.

Pull requests are welcome at the [ofxtools repository on GitHub](https://github.com/csingley/ofxtools).
Please open an issue first for non-trivial changes so we can discuss the approach.
